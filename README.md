# 오늘 뭐 입지 (가족 코디 앱)

가진 옷을 사진으로 저장하고, 날씨와 색 궁합에 맞춰 코디를 추천해 주는 무료 웹앱입니다.
서버·결제·API 키가 없고, 옷 사진은 각자 폰 브라우저 안에만 저장됩니다.

## 기능
- **오늘**: 날씨(Open-Meteo, 무료)에 맞는 두께/겉옷으로 옷장에서 코디 1개 추천
- **옷장**: 옷 사진 촬영·저장(색 자동 인식, 종류/두께 선택)
- **짝 찾기**: 흰 바지 같은 옷을 고르면 옷장에서 어울리는 옷 추천
- **색 조합**: 색을 누르면 어울리는 코디를 남편 사진 위에 색을 바꿔 보여 줌 (30가지 색, `assets/man.jpg` + 구역 마스크)

## 폰에서 쓰기 (무료 배포: GitHub Pages)
1. 저장소 Settings → Pages → Branch를 `main` / `(root)`로 선택 → Save
2. 잠시 후 나오는 주소를 폰에서 열기
3. 아이폰: 공유 → 홈 화면에 추가 / 안드로이드: 메뉴 → 홈 화면에 추가

## 개발
```
npm start   # http://localhost:8080
npm test    # 색·코디 규칙 테스트
```
